# v2 文档索引

`docs/v2` 按文档用途分为三类：

```text
设计方案/
  长期维护的架构和系统设计。实现发生变化时，这里的文档也要同步更新。

参考资料/
  支撑设计和迁移的资料库。它可以持续补充，允许保留过程性备注，正式 schema 以设计方案为准。

阶段记录/
  阶段性验证、构建步骤、手动检查项和当时的限制。它用于保留历史上下文。
```

## 维护规则

- 新增长期设计时，优先放进 `设计方案/`。
- 某一阶段的过程、验收或临时限制，放进 `阶段记录/`。
- 资源盘点、调研资料、旧行为对照等辅助内容，放进 `参考资料/`。
- 阶段记录里的内容沉淀为长期决策后，应同步到 `设计方案/`。

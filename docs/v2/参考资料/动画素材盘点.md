# 动画素材盘点

本文档用于登记 v2 动画系统中的 GIF 素材。每个 GIF 都应有记录位置，便于逐项补充语义、朝向、播放建议和适用场景。

相关文档分工：

- `../设计方案/皮肤包播放行为设计.md`：定义正式层级模型，例如 Clip、Action、Recipe、ActionPool、BehaviorRule。
- `../设计方案/桌宠运行时与动画调度设计.md`：解释 Pet Runtime 总体职责和调度原则。
- 本文：记录旧素材事实、语义标注、朝向判断和拆 phase 线索。

本文里的“进入 / 循环 / 退出”和 GIF 帧段范围属于迁移线索，最终会沉淀为 Clip / Action / Recipe 配置。运行时读取正式皮肤配置。

旧版素材主要分为五类：

- `stand/`：站立/待机循环。
- `walk/`：8 方向行走循环。
- `run/`：8 方向奔跑循环。
- `once/`：数字命名的一次性动作，语义需要逐步复核。
- `special/`：旧版已按动作语义命名的特殊动作。

## 填写约定

- `语义` 写目前能确认或初步判断的动作含义。
- `朝向` 写 `right`、`left`、`8-direction`、`unknown` 或更具体方向。
- `播放建议` 写 `loop`、`onceThenIdle`、`hold`、`phased` 或 `unknown`。该字段只作为迁移提示，最终播放方式以 Recipe 为准。
- `状态` 写 `已接入`、`待接入`、`待你确认`。
- 不确定的条目统一写 `待你确认`，保持素材事实和语义判断可追踪。

## 朝向约定

已知规律：

- `stand/0.gif`：朝右站立。
- `stand/1.gif`：朝左站立。
- `once/4.gif`：朝右抱胸思考。
- `once/5.gif`：朝左抱胸思考。
- `special/*0.gif` 通常作为朝右资源。
- `special/*1.gif` 通常作为朝左资源。

该规律需要在逐个动作验收时继续复核。若某个动作方向相反，优先调整 manifest/qrc alias，保持运行时接口稳定。

## 整理规则

- manifest 使用稳定 action id，例如 `objecting`、`bow`、`sleeping`，运行时代码通过 action id 引用资源。
- 同一 action 的左右朝向放在 `variants.right` / `variants.left`。
- 动作能否循环由 `loopMode` 表达，不靠文件夹名推断。
- 素材语义不确定时，在文档里标“待你确认”，等待逐项复核后再确定最终命名。
- 动作需要拆成 `enter` / `loop` / `exit` 时，优先在 manifest 里拆阶段，运行时接口保持稳定。

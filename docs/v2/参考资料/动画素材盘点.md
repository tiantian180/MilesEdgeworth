# 动画素材盘点

本文档是 v2 迁移期间的素材语义盘点表，用来记录现有 GIF 的实际含义、朝向、帧段备注和实现线索。后续还原旧版桌宠手感、整理皮肤 manifest、拆分 Clip/Action/Recipe 时，会反复查阅这里的素材事实。

本文属于过程资料，不作为正式 schema，也不承担长期架构设计职责。正式层级模型以这些文档为准：

- `../设计方案/皮肤包播放行为设计.md`：定义正式层级模型，例如 Clip、Action、Recipe、ActionPool、BehaviorRule。
- `../设计方案/桌宠运行时与动画调度设计.md`：解释 Pet Runtime 总体职责和调度原则。

本文里的“进入 / 循环 / 退出”和 GIF 帧段范围都是迁移线索，最终会沉淀为 Clip / Action / Recipe 配置。`loopMode 建议` 只表示当前观察到的粗略播放倾向，不是最终运行时策略。

当前 Miles 皮肤包资源位于 `apps/desktop/resources/skins/miles-edgeworth/assets/`，主要分为这些目录：

- `body/idle/`：站立/待机循环。
- `body/locomotion/`：8 方向行走和奔跑循环。
- `body/gestures/`：原 `once/` 目录迁入的一次性动作。
- `body/interaction/`：双击、点击、拖拽、徽章后续等交互动作。
- `body/menu/`：右键菜单触发动作。
- `body/rest/`：睡眠、睡眠循环和唤醒动作。
- `props/`：检察官徽章等独立 Prop 图片。
- `audio/voice/`：当前语音资源，`audio/voice/legacy/` 保存旧版备份语音。
- `source/`：PSD 等源工程文件。

## 填写约定

- `语义` 写目前能确认或初步判断的动作含义。
- `朝向` 写 `right`、`left`、`8-direction`、`unknown` 或更具体方向。
- `loopMode 建议` 写 `loop`、`onceThenIdle`、`hold` 或 `unknown`。该字段只作为迁移提示，最终播放方式以 Recipe 为准。
- `状态` 写 `已接入`、`待接入`、`待你确认`。
- 不确定的条目统一写 `待你确认`，保持素材事实和语义判断可追踪。

## 朝向约定

旧版命名规律：

- `gifs/stand/0.gif` 迁移为 `body/idle/stand-right.gif`。
- `gifs/stand/1.gif` 迁移为 `body/idle/stand-left.gif`。
- `gifs/once/4.gif` 迁移为 `body/gestures/thinking-right.gif`。
- `gifs/once/5.gif` 迁移为 `body/gestures/thinking-left.gif`。
- `special/*0.gif` 通常作为朝右资源。
- `special/*1.gif` 通常作为朝左资源。

该规律需要在逐个动作验收时继续复核。若某个动作方向相反，优先调整 manifest/qrc alias，保持运行时接口稳定。

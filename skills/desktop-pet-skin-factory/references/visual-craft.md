# 视觉打磨

让作品有明确的设计意图、可信的结构和独特的性格。用户说“AI 味重、塑料、太假”时，把反馈转成具体可改的画面问题。

## 保留风格，修好细节

华丽、发光、对称或 3D 风格本身都可以成立。打磨不等于删光特效、强制写实或加噪点做旧；保持用户选定的画风与主题。

| 画面问题 | 调整方式 |
| --- | --- |
| 毛发表面像涂蜡，体积被磨平 | 按参考恢复毛束方向、疏密与形体，区分毛发、眼睛和金属的反光 |
| 羽片、鳞片或壳纹融成装饰 | 恢复分区、重叠和纹理方向；按实际结构处理，不套毛绒材质 |
| 所有材质都是同一种亮面 | 区分高光范围、折面、褶皱和柔软度，先处理主要形体 |
| 配件与身体粘连 | 明确连接点、接触边界与前后遮挡，转身时保持穿戴关系 |
| 任何主题都只是光圈围着角色 | 让主题道具参与身体动作，改变构图、节奏与结果 |
| 全身同时发亮，主体被吞没 | 根据主光与局部特效安排明暗，让关键动作先被读懂 |
| 播放时纹理跳动、配件闪现 | 对比定位后 PNG 和解码后的 GIF，分别处理生成变化与编码问题 |

只使用与当前宠物相关的项目。玩具、赛璐璐或幻想材质可以光滑，鱼鳍也不必一律透明。

## 局部修改的写法

说明“哪一帧的哪个部位，改成什么，保留什么”，比堆叠“高级、自然、8K”更有效。

例如：保留这只鸟的喙形、翼部标记和星帆设计，只修展开区间的羽片粘连与翼根配件穿插。按选定姿态保持羽片分组和连续轨迹，不改变角色画风。

表演单薄时先调整主体动作和道具关系；材质不对时只修相关材质。细节没有问题时保留当前版本，不为制造前后对比重新生成。

## 看最终效果

在相同显示尺寸、背景和动作时刻比较修前修后。先确认角色仍像它自己，再看问题是否改善、主题是否完整、是否产生新穿插或透明瑕疵。

动态看原速与慢速，静态只看相应画面。把需要继续调整的地方记在制作说明里，使用当前文件版本。保持真实的工具与来源记录；视觉打磨不是 AI 来源检测，也不代表真人手绘。

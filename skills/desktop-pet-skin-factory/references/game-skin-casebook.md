# 游戏皮肤设计灵感

学习游戏皮肤如何把装扮、动作和特效做成完整主题，再用自己的宠物、故事与造型表达。以下为设计阅读，不附带游戏素材或成品动画。

## 让主题贯穿全身

[王者荣耀 · 貂蝉「唤灵魅影」](https://www.taptap.cn/moment/268029219232025314) 的官方设计介绍将服饰火纹、火灵、火绸带和法阵围绕同一主题组织。

用于宠物创作时，可以先选一种有行为能力的主题材料，例如会折叠的云帆、能生长的晶枝或流动的行情光带。它既参与装扮，也决定动作高潮和收势方式。

## 把装扮延伸成体验

[阴阳师 · 孔雀明王「青鳥の誓い」介绍](https://www.onmyojigame.jp/news/update/2024/06/25/25566_1163129.html) 涉及动作、特效与其他角色表现。

桌宠可以采用成套设计思路：常态有标志形象，互动有独特表演，休息也延续同一主题。具体交付按用户需要，不因参考游戏就添加语音、剧情或付费系统。

## 华丽仍要清楚

[Riot · Clarity in League](https://www.leagueoflegends.com/en-us/news/dev/clarity-in-league/) 讨论角色识别与视觉层级；[League's VFX Style Guide](https://nexus.leagueoflegends.com/en-us/2017/10/dev-leagues-vfx-style-guide/) 介绍清晰、主题与视觉表现。

用到桌宠时，让主体动作先被看见，再安排后景召唤物、近身道具与前景粒子。安静待机和高光表演形成对比，不让所有层同时抢焦点。

## 转成自己的设计

为参考写一句“学习什么”，再落实到本套的装扮、道具或动作。文字介绍用于理解概念；具体动作时序需实际观看动画，不从海报推算帧数。游戏名称不能代替分镜设计，参考人物、纹章、配音和原画也不直接放进交付包。

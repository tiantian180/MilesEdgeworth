# 造型与表演设计

把皮肤作为一套完整体验来设计：角色形象、装扮、道具、动作和特效共同表达同一个主题。

## 认识这只宠物

先查看参考，选择当前使用的角色定稿。记录个体轮廓、比例、标志花纹和画风，以及实际身体部位、数量与材质。服饰可以丰富，角色仍应一眼可认。

已有数字角色沿用原形象。照片转绘先确定风格化程度；原创角色先建立形象。只有一张参考时不必补齐三视图，未知部分作为设计选择与用户沟通。

角色参考说明“是谁”，装扮参考说明“穿什么”，邻近姿势说明“怎么动”。制作时按用途组合参考，不用已经变样的输出替代角色定稿。转身可以改变屏幕左右，但实际部位和非对称标记要保持对应。

## 按身体设计动作

| 角色与动作 | 设计重点 |
| --- | --- |
| 陆地移动或停驻 | 实际支撑点、重心转移、步态与缓冲，不统一套四足走路 |
| 翼部展开和飞行 | 翼根连接、折叠展开、羽片层次和身体轨迹 |
| 游动或无足身体 | 主体形变、实际鳍尾的配合，以及流线与节奏 |
| 拟人化或幻想变形 | 明确变化规则，保留识别特征，设计连贯的进入和恢复过程 |

原地表演可固定身体；飞行、跃起和游动画内位移使用固定画布参考，具体定位见 [帧编排](frame-pipeline.md)。毛、羽、鳞、壳和幻想材质各有自己的形体与反光，不做统一毛绒化处理。

## 一句话主题

先写角色想做什么，例如“把云朵酿成茶，送给路过的星星”。然后确定：

- 常态装扮或标志造型，以及服饰与身体的连接方式。
- 主辅材质、配色用途、轮廓焦点和共用图形。
- 道具的功能、能量来源、特效展开与消散方式。
- 安静待机、轻互动与主动高光各自的表现强度。

华丽来自完整设计，不是装饰数量。高光可以有大型召唤物、空间变化和超现实道具；主体仍要清楚。没有服装也能成立，但载具、形态或主题空间应承担完整造型。

## 整套动作

在设计简报中为每段写清：触发方式、主体动作、道具关系、准备→高潮→收势、循环或单次、与其他表演的区别。数量按需求决定，镜像、改色和帧率变化不算新表演。

让道具真正参与动作：接住后才变形，接触时才反弹，开门后才释放召唤物。关键接触比背景火花更亮、更容易读懂。

分层可以使用后景承托、身体与装扮、近身道具、前景强调，不要求每帧全开。大场面先安排在目标画布内，保持桌宠的合理显示尺寸。待机安静，主动触发时再展开高光；沿用软件已有的减少动态设置。

## 原创设计示例

以下是创作思路，不是附带成品，也不是所有物种的统一动作模板。

### 股票主题 · 猫

保留个体特征，用鎏金短披肩和 K 线领饰建立造型。行情光带既是能量，也是能变形的道具。

| 表演 | 身体动作与特效关系 |
| --- | --- |
| 开盘降临 | 穿过 K 线拱门，落爪触发钟波；门片收进领饰 |
| 涨停冲浪 | 压住蜡烛图滑板、倾身转弯，行情光带随轨迹弯曲 |
| 牛市觉醒 | 蓄力下踏，金牛影从身后展开，台阶沿落爪方向升起 |
| 熊市护盾 | 伏低拨伞，绿图带织成穹顶，方块触盾化成鱼形水滴 |
| 落袋为安 | 追视、接住、搂回，金币沿轨迹聚成鱼，再送回金库 |
| 收盘躺平 | 踩上光带吊床后蜷卧，小牛小熊收成安静的两端支架 |

### 云端茶馆 · 鸟

翼部展开带出折叠茶帆，露珠沿帆汇成茶滴；鸟用喙拨动杯柄，茶杯沿气流送出，收翼时云汽回到茶壶。羽片、星帆与蒸汽形成三种不同材质。

### 潮汐宝库 · 鱼

鱼尾摆动打开贝壳星门，游弧牵引珍珠轨道；穿过轨道时珍珠化成短暂星群，再顺水流收回宝库。表演由游姿和鳍尾驱动，不添加抓握的爪子。

## 定稿与样板

选一段同时体现身份、装扮、主体运动和代表特效的样板，先完成少量关键姿势与短段 GIF。用实际尺寸看主体、边界和高潮，再展开整套。已有明确方向时直接推进；需要比较候选时，在相同背景和尺寸下看轮廓、主题与修改空间。

成套播放时保持同一角色尺度和装扮规则，重点看真实支持的相邻状态切换。局部细节按 [视觉打磨](visual-craft.md) 处理。游戏皮肤灵感见 [设计案例](game-skin-casebook.md)。

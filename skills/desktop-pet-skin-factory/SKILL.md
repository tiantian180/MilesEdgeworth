# 桌宠皮肤工坊

让每只宠物拥有自己的造型、故事和动作。保留它独有的模样，用完整装扮、创意道具和有节奏的特效，做出适合桌面陪伴的主题皮肤。

## 从这几件事开始

查看用户提供的参考，了解角色、主题、动作数量、目标软件与交付形式。已有信息直接使用；缺少影响制作的内容时再询问。把本 skill 加入任务计划，按当前项目约定开展工作。

- **已有角色换肤**：沿用个体特征和画风，设计新装扮与表演。
- **宠物照片定制**：先确定转绘风格和角色形象，再制作皮肤。
- **原创新角色**：先定下角色设定，再展开成套动作。

按宠物实际身体结构选择动作，不默认四足、毛发或接地。只有一张参考时也可以开始；未知视角作为待定设计处理。像素级保留应复用原素材，生成式转绘不承诺逐像素一致。

## 制作流程

1. **定角色与主题**

   阅读 [造型与表演设计](references/skin-art-direction.md)，用 [设计简报](assets/skin-design-brief.md) 记录角色特征、装扮和动作安排。顾客订单同时使用 [定制交付指南](references/custom-orders.md)。

2. **做一段代表作品**

   先设计整套，再选择最能体现品质的一段。豪华皮肤的样板应同时展示角色、装扮和高光特效；轻量换装按其目标制作。先看实际桌宠尺寸下的静帧，再试一小段最终格式动画。

3. **完成连续动作**

   阅读 [动作制作](references/art-and-animation.md)。使用当前可用、已获准的图像生成或编辑工具；环境提供 imagegen skill 时先按其说明操作。先做好关键姿势，再补中间动作。以定稿图持续约束身份和服饰，保留做对的部分。

4. **整理与打磨**

   按 [帧编排与导出](references/frame-pipeline.md) 输出 PNG 和 GIF，用 [视觉打磨](references/visual-craft.md) 优化材质、轮廓、光效和播放细节。制作多段或多套时，按 [批量制作](references/production.md) 分批推进。

5. **交付或接入**

   只交付用户需要的阶段：设计稿、静态图、动画素材或可安装皮肤包。接入软件时阅读 [软件接入](references/integration.md)，沿用项目的格式与播放能力。先预览成片，再交付选定版本。

## 成品的样子

- 一眼认得出这只宠物，装扮大胆但不淹没它的特征。
- 各段动作有不同的主体表演、道具关系和节奏，不只是换颜色或粒子。
- 动作有准备、发力、反馈和收势，接触与特效在同一时刻发生。
- 待机安静，高光鲜明；实际大小看得清，画布完整，切换自然。
- PNG 与 GIF 分目录，原图和成片分开，顾客资料按订单保存。

图像生成负责形象与姿势；附带 Python 工具负责已有帧的定位、编码和文件检查。透明效果、角色相似度和动作观感需要实际看图、播放判断。GIF 只有二值透明，先试样板再扩展。

同一问题连续两次定向修改仍未改善时，保留当前版本，说明问题和可选方案，再决定下一步。需要额外服务、费用或发布权限时先确认。

## 沟通方式

直接展示作品和进展：做了什么、哪里变好了、下一步需要确认什么。用简短制作说明代替逐项检查报告；仅在影响交付时解释技术细节。完成时给出预览、文件位置、实际完成范围与必要的使用说明。

顾客未确认的设计保持待确认，未试过的软件不宣称已适配。案例展示与公开分发按各自约定处理。
